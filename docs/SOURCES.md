## Reading order

If you only read four things before designing an agent system:

1. **AWS Agentic AI Security Scoping Matrix** — puts a name on how much agency you are actually granting, and what changes at each step.
2. **OWASP Top 10 for Agentic Applications 2026** — the failure catalogue, written for people shipping rather than reviewing.
3. **SandboxEscapeBench** — calibrates how much you should trust "it runs in a container".
4. **τ-bench** — explains why pass@1 flatters an agent and what pass^k measures instead.

Then, depending on what you are building: **Anthropic's Building Effective AI Agents** for shape, **OWASP AISVS C09** for testable requirements, **NIST AI 600-1** for the risk register, and **Saber / Procedure-Aware Evaluation** for how to evaluate an agent that mutates state.
